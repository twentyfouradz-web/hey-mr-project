HEY MR API ROUTES — ADMIN-ONLY AD POSTING
==========================================

PUBLIC APIs
GET    /api/health                         Health API
GET    /api/public/categories               Public Categories API
GET    /api/public/districts                 Public District API
GET    /api/public/areas?district=...        Public Areas API
GET    /api/public/ads                       Public Ads API (supports paging/search/filters)
GET    /api/public/search?q=...              Search API
GET    /api/public/filter?...                Filter API
GET    /api/public/settings                  Public Website Settings
GET    /api/public/contact-settings          Public Contact Settings
GET    /api/images/{key}                     Read an R2 image

ADMIN AUTHENTICATION
POST   /api/admin/login                      Admin Login API

ADMIN APIs (Bearer token required)
GET    /api/admin/dashboard                  Admin Dashboard API
GET/POST /api/admin/ads                      Add Ads API / Ads list
PATCH/DELETE /api/admin/ads/{id}             Edit Ads API / Delete Ads API
POST   /api/admin/ads/bulk                   Bulk Ads API
                                            action=create with ads[]
                                            action=status with ids[] and status
                                            action=delete with ids[]
POST   /api/admin/images/upload              R2 Image Upload API (multipart field: image)
DELETE /api/admin/images/{key}               Image Delete API
GET/POST /api/admin/vip                      VIP API
POST   /api/admin/vip/{id}/activate           Activate VIP promotion
GET/PUT /api/admin/contact-settings          Contact Settings API
GET/PUT /api/admin/settings                  Website Settings API
GET/POST /api/admin/form-fields              Form Fields API
DELETE /api/admin/form-fields/{id}           Delete Form Field API
GET    /api/admin/inbox?ad_id=...             Chat / Inbox API
POST   /api/admin/inbox/reply                 Chat / Inbox Reply API
GET    /api/admin/chat                       Alias for inbox list
POST   /api/admin/chat/reply                 Alias for inbox reply

SECURITY AND PROJECT RULES
- POST /api/admin/ads and all management endpoints require an Admin bearer token.
- Admin-created ads are published immediately (no admin-approval queue) and receive the configured 7-day VIP placement, matching the existing project behavior.
- Public visitors can browse, search and filter ads; they cannot create or manage ads.
- Image upload accepts JPG, PNG, WEBP and GIF up to 5 MB; files are stored in the configured R2 bucket.
- Chat/inbox endpoints are Admin-only and use the existing chat_messages table from migration 0002_client_chat.sql.
- The homepage and existing Admin Panel interface are intentionally preserved. These are API additions; the existing pages are not redesigned.
- Do not configure Razorpay, MSG91 or a custom domain as part of this ZIP update; those remain deferred.

DATABASE MIGRATIONS
Apply migrations in order, including 0002_client_chat.sql for the chat_messages table:
  wrangler d1 migrations apply hey-mr-database --remote
